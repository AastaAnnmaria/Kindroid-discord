# 習慣打卡 · Habit Tracker

一個純本地、不需安裝、不需登入的習慣記錄 App。打開瀏覽器就能用，資料只存在你自己的裝置上。

## 怎麼用

直接用瀏覽器打開 `index.html` 即可（雙擊檔案，或拖進瀏覽器視窗）。

不需要 Node、不需要 `npm install`、不需要連網。

## 功能

- **多個習慣項目**：預設已建立「只喝水、運動/步數達標、讀書半小時、12 點前睡覺、Eat healthy」，可自行新增、編輯、刪除，每個項目都能自訂 emoji 與名稱。
- **每日打卡**：點右側圓圈完成今天的打卡，再點一次可取消。
- **連續天數累積**：每張卡片顯示「目前連續 N 天」，會一直往上累積。
- **最高連擊**：每張卡片標出該習慣的歷史 🔥 最高連擊；頂部摘要也會顯示所有習慣中的最高紀錄。
- **一週進度條**：每個習慣有一週 7 天（週一～週日）的進度條與每日小格，完成就點亮；**每週一自動刷新**（進度條只看本週）。
- **頂部摘要**：今日已完成項目數、本週打卡總次數、最高連擊。
- **補打卡**：本週的任一天小格都可以點擊補登或取消（未來的日期不能點）。
- **匯出 / 匯入備份**：可把資料存成 JSON 檔備份，或在另一台裝置／清除瀏覽器資料後匯入還原。

## 資料儲存

所有資料存在瀏覽器的 `localStorage`（key：`habitTracker.v1`），不會上傳到任何伺服器。

> 注意：清除瀏覽器資料、或換不同瀏覽器／裝置，資料不會自動跟著走。需要轉移時請用「匯出備份 → 匯入備份」。

## 檔案結構

- `index.html` — 頁面結構
- `styles.css` — 樣式（深色主題）
- `app.js` — 全部邏輯（無框架、無建置流程）
